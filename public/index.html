SIMULADOR CAIXA

Este simulador habitacional estima o financiamento de imóveis novos e lançamentos. Em poucos campos, o simulador de financiamento mostra uma leitura simples das condições.

No simulador Caixa, a consulta leva poucos segundos e vale apenas para imóveis novos e lançamentos. Use o resultado como referência antes de falar com o corretor ou seguir para a análise de crédito.

Perguntas frequentes

Para quais imóveis este simulador serve?

Este simulador de financiamento é exclusivo para imóveis novos e lançamentos.

O simulador Caixa é um serviço oficial da Caixa?

Não. Este simulador é independente e não é um serviço oficial da Caixa Econômica Federal. Os valores são estimativas.

Quais dados a simulação pede?

Nome, CPF, contato, renda familiar, valor do imóvel, estado, cidade e região. O simulador habitacional usa esses dados para consultar as condições.

Em quanto tempo aparece o resultado?

Na maior parte dos casos, o simulador Caixa mostra o resultado em segundos depois do envio.
